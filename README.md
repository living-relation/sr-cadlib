# SR CADLib

A Spark Robotic Fusion API scripting helper library.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## Features

- Helpers for primitives, sketches, and extrudes.
- Helpers for materials and placement.
- Helpers for saving to Fusion data folders.
- A part registry.

The exact functions, arguments, and module layout are to be completed when the code lands.

## Requirements

- Autodesk Fusion

Other dependencies, if any, are to be completed when the code lands.

## Install

Clone this repository and make the library available to your Fusion Python scripts. The import path, packaging, and any extra install steps are to be completed when the code lands. See [docs/install.md](docs/install.md).

## Usage

From a Fusion script or add-in, import SR CADLib and call its helpers instead of repeating low-level Fusion API boilerplate. Command names, examples, and return values are to be completed when the code lands. See [docs/usage.md](docs/usage.md).
