# Usage

Once the library is available in Fusion, import it from a Fusion Python script or add-in and call its helpers for primitives, sketches, extrudes, materials, placement, saving to data folders, and the part registry.

The library code is not in this repository yet, so the steps below stay at a high level.

## Before you start

1. Install the library as described in [Install](install.md).
2. Open or create the Fusion design your script will work in.
3. Run your script or add-in from Fusion in the usual way.
